확인 방법
  1. 고용주로 로그인한 뒤 목록을 조회하고 확정 근무를 선택하세요.
  2. 완료 처리 전에는 완료 일시가 비어 있습니다. 약정 종료 시각이 지난 근무를 완료하면 POST 200과 저장 시각을 확인할 수 있습니다.
  3. 자동으로 실행한 상세 GET 200의 완료 일시가 POST 응답과 같으면 저장값 일치 안내가 나옵니다.
  4. 완료된 근무를 다시 요청하면 200이며 최초 완료 일시가 유지됩니다.
  5. 종료 전 또는 취소·조기 종료된 다른 근무를 선택하면 409와 오류 코드를 확인할 수 있습니다.

근무 시간이나 상태를 이 화면에서 조작하지 않습니다. 처리 도중 연결이 끊기면 자동 재요청하지 않고 상세를 다시 조회해 저장 여부를 확인하세요. 근로자는 기존 좌표 demo의 본인 약정 상세에서도 같은 완료 시각을 조회할 수 있습니다.

등록·미등록·변경 반영 확인 순서
  1. 근로자로 로그인한 뒤 이 화면에서 조회하세요.
  2. 위 계좌 관리 링크로 새 창을 열고 가상 계좌를 등록하세요.
  3. 이 화면으로 돌아와 조회하면 registered=true와 은행 코드를 확인할 수 있습니다.
  4. 관리 창에서 다른 은행으로 교체하고 다시 조회해 은행 코드 변경을 확인하세요.
  5. 관리 창에서 계좌를 해제하고 다시 조회하면 registered=false·bankCode=null입니다.

같은 은행 안에서 계좌번호만 바꾸면 보험 응답은 같을 수 있습니다. 계좌번호·마스킹 번호·예금주·계좌 버전은 제공하지 않습니다. 변경 후에는 조회 버튼을 눌러 주세요.

새 화면에는 토큰·회원 ID 입력 칸이 없습니다. 다른 회원 ID를 쿼리에 넣어도 조회 대상을 바꾸지 않습니다. 등록 여부는 저장된 계좌의 존재 여부이며 실계좌 확인 결과가 아닙니다.

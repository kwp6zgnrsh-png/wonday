새 계좌 등록 · 기존 계좌 교체

은행을 선택하면 계좌번호를 입력할 수 있습니다.

하이픈 제거 후 숫자 1~30자리입니다. 저장 후 조회에서는 마스킹합니다.

마스킹된 기존 번호를 입력 칸에 넣지 않습니다. 교체할 새 계좌번호 전체를 입력하세요.

해제하면 현재 급여 계좌가 삭제됩니다. 미등록 상태에서 다시 해제해도 204입니다.

요청 결과

아직 요청하지 않았습니다.

상태 코드와 마스킹된 응답이 여기에 표시됩니다.
마스킹 · 409 확인 방법
  • 가상 번호 12345를 저장하면 *2345, 1234를 저장하면 ****로 조회됩니다.
  • 같은 계정으로 이 화면을 두 창에서 열고, 양쪽 모두 최신 계좌를 조회하세요.
  • 창 A에서 저장한 뒤 창 B에서는 조회하지 않고 저장 또는 해제를 누르세요. 409를 확인할 수 있습니다.
  • 창 B에서 최신 계좌를 조회하고 내용을 확인한 뒤 다시 저장할 수 있습니다.

다른 창의 변경은 자동 반영하지 않습니다. 409 이후 자동 저장이나 자동 재시도도 하지 않습니다.

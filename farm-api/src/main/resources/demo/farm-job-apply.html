새 가상 공고에 미래의 세 날짜를 만듭니다. 첫째·둘째는 신규 지원용, 셋째는 내 미선정 1회차가 있어 재지원용입니다. 기존 공고나 지원은 바꾸지 않습니다.

오늘 같은 계정으로 다시 누르면 준비한 공고를 엽니다. 이전 지원·수정 이력을 초기화하지 않습니다. 고용주는 demo-employer입니다.

5. 버전 충돌 · 재지원 확인 순서

  1. 시연용 공고를 준비한 뒤 첫째 날짜만 선택해 지원하세요. 201과 새 지원 ID를 확인합니다.
  2. 같은 요청 재전송을 누르면 200이며 ID·회차·접수 시각 유지 여부를 비교합니다.
  3. 아직 지원하지 않은 둘째 날짜를 선택하고 ‘현재 조건으로 요청만 준비’를 누르세요.
  4. 별도의 시크릿 창에서 demo-employer로 로그인해 /demo/jobs의 이 공고에서 둘째 날짜의 시간을 실제로 수정하세요.
  5. 근로자 창에서 새로 조회하지 않고 ‘선택 날짜 지원’을 누르면 보관한 이전 버전으로 전송해 409 SCHEDULE_TERMS_CHANGED를 확인할 수 있습니다.
  6. ‘최신 조건 · 내 이력 조회’ 후 둘째 날짜를 다시 선택해 지원하면 새 키·최신 버전으로 접수합니다.
  7. 셋째 날짜를 선택해 지원하면 미선정 1회차를 보존하고 2회차가 생기는지 이력 표에서 확인합니다.

같은 브라우저의 일반 탭끼리는 로그인 쿠키를 공유합니다. 고용주 수정은 시크릿 창 등 별도 로그인 세션에서 진행하세요. 버전 충돌을 화면에서 가짜로 만들거나 기존 지원을 미선정으로 바꾸는 기능은 없습니다.

# STEP04 구현 상태와 남은 작업

2026-11-24 기준. **초기 구현·실제 산출·원인 진단 단계이며, 복원자료를 반영한 최종 모델이나 성능 검증 완료본이 아닙니다.**

## 이번 커밋에 포함하는 범위

- 강수·강풍 AI1과 온열 AI2의 Isolation Forest 주 모델 두 개 구현. 보조 모델은 없습니다.
- 모델별 완전 입력 행만 학습·추론하고 제외 행·사유를 보존합니다.
- 2016~2023년 학습, 2024~2025년 평가, 2026년 추가기간을 분리합니다.
- 학습점수 분포의 ECDF로 AI 이상지수를 0~100점으로 변환합니다.
- 모델 저장·재로딩, 기간 분리, 제외율, STEP03 공통 집계 대조와 자동 테스트를 제공합니다.
- 자정 원본 누락과 누적계 초기화, 신북면 풍속 결측의 진단 및 코드 리뷰·조회 명령을 기록했습니다.
- 자동 테스트 21개와 기존 저장 결과 검증을 통과했습니다. 이는 탐지 성능이나 통계적 유의성의 검증을 뜻하지 않습니다.

원본 CSV·정제자료·생성 모델·대용량 결과·전용 Python 환경은 이번 소스 커밋에 포함하지 않습니다. 기존 저장소의 worker/data 제외 정책을 유지합니다. 로컬 실험으로 확보한 공식 일자료와 복원 후보는 생산 입력과 분리했으며, 생산용 복원 기능은 아직 구현하지 않았습니다.

## 공식 일강수량 복원 검토 결과

평가기간의 선행강수 결측 7,264행을 대상으로 같은 관측소의 공식 일자료와 08:00 누적값을 대조했습니다. 필요한 공식 일자료 17,544건 중 17,534건을 확보했습니다. 이 확인은 평가기간 대상 로컬 실험이며 학습기간 전체 확보·생산 반영을 완료한 것이 아닙니다.

| 구분 | 건수 |
| --- | ---: |
| 자정 외 구간·공식 일총량·기준 누적값의 조건을 충족한 보수적 복원 후보 | 6,771 |
| 다른 시간에도 누락이 있어 추가 검토가 필요한 후보 | 210 |
| 08:00 누적값 결측·누적계 감소·공식 일자료 결측으로 보류 | 283 |

보수적 후보를 반영할 수 있다면 다른 AI1 특성도 완전한 6,380행을 추가 활용할 수 있습니다. 평가 입력 가능 행은 16,206행, 제외율은 약 7.63%가 되는 조건부 계산이며 실제 점수 재산출 결과가 아닙니다.

기존 선행강수 완전 행 10,280건에 같은 일자료 기반 식을 적용한 대조에서는 1건이 불일치했습니다. 이천 진암리 2024-12-10 작업일의 기존 선행강수 0mm와 공식 일자료 기반 1mm 차이는 추가 확인 대상입니다.

## 반드시 이어서 할 작업

- [ ] 2016~2023년 학습기간의 같은 관측소 공식 일강수량을 확보하고 품질·시각 기준을 확인합니다.
- [ ] 전날 공식 일강수량 − 전날 작업 시작 누적값 + 당일 작업 시작 누적값의 복원 로직을 구현합니다.
- [ ] 관측·공식 일자료·복원값의 출처, 품질 상태, 남은 결측 사유를 구분해 기록합니다.
- [ ] 원래 없는 자정 행이 현재 전처리의 최종 frame에 생성되지 않는 문제를 포함해 반영 경로를 결정합니다. 일자료 파일 추가만으로 자동 해결되지 않습니다.
- [ ] 누적계 감소, 08:00 값 결측, 공식 자료와 기존 값 불일치, 윤일 조회 누락을 검증합니다.
- [ ] 학습에 포함된 작업시간 최고기온 −40℃ 등 센서 의심값을 점검합니다.
- [ ] 보완 후 2023년까지의 자료만으로 재학습하고 ECDF를 다시 생성합니다. 평가·추가기간 자료를 학습에 섞지 않습니다.
- [ ] 단순 기상 기준·기존 개별 지수와 비교해 IF의 추가 가치를 평가합니다.
- [ ] 학습기간 안에서 시간순 검증, 난수 시드별 순위 안정성, 특성별 기여와 강풍 표본 부족을 점검합니다.
- [ ] 관측소·계절·주요 사건별 계산률과 상위 이상점수를 검토합니다. 평가 결과를 유리하게 만들기 위해 기준을 재학습하지 않습니다.

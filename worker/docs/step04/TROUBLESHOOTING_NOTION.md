# STEP04 AI1 평가자료 제외율 원인과 후속 조치

상태: 원인 진단 완료, 데이터 보완과 정책 변경은 미적용

AI1 평가자료의 43.99% 제외는 모델 학습 오류보다 입력자료의 자정 구간 문제에서 주로 발생한다. 특히 2024년 183일 동안 모든 관측소의 자정 행이 로컬 원본 CSV에 없으며, 별도로 24:00 누적강수량 0을 보수적으로 결측 처리하는 전처리 규칙이 적용됐다. 현재 결과는 전체 평가기간을 대표하는 성능 검증으로 해석하기 어렵다.

## 문제 현상

| 항목 | 확인 결과 |
| --- | --- |
| 평가 대상 | 2024~2025년, 24개 관측소, 17,544행 |
| AI1 계산 | 9,826행 |
| AI1 입력 부족 제외 | 7,718행, 43.99% |
| 선행 24시간 강수 불완전 | 7,264행, 전체의 41.40% |
| 2024년 AI1 제외율 | 5,502 / 8,784행, 62.64% |
| 2025년 AI1 제외율 | 2,216 / 8,760행, 25.30% |

AI1은 강수량·선행강수량·최대 평균풍속·강수시간·강풍시간이 모두 완전해야 계산한다. 아래의 구간 수는 10분 관측 단위이며 작업일 행 수와 구분해야 한다.

## 선행강수 불완전 행의 분해

다음 세 집단은 서로 겹치지 않으며 합계가 7,264행이다.

| 불완전 작업일의 유형 | 작업일 행 수 | 확인 내용 |
| --- | ---: | --- |
| 유일한 결측이 자정 원본 행 부재 | 4,293 | 해당 시각의 행이 정제자료와 로컬 원본 모두에 없음 |
| 유일한 결측이 24:00 누적값 0 처리 | 2,468 | 원본 행은 있지만 전처리가 증분을 결측으로 보존 |
| 그 밖의 원인 또는 복수 결측 | 503 | 다른 시각 행 부재, 누적값 결측, 이전 기준값 부족, 음의 차분 등 |

자정 원본 행 부재만 있는 집단과 자정 누적값 0 처리만 있는 집단이 6,761행이다. 선행강수 불완전 작업일 대부분은 하루 전체 자료가 사라진 경우가 아니라 자정 경계 한 구간 때문에 계산되지 않았다.

## P0 모든 관측소의 공통 자정 원본 행 부재

**2024-04-10~2024-10-09의 183일 동안 24개 관측소 모두 00:00 구간 종료 행이 없다.** 원본 표기로는 전날인 2024-04-09~2024-10-08의 24:00 행이다.

이 기간의 관측소·작업일 4,392행은 AI1 계산이 전부 불가능하다. 같은 기간 AI2는 4,315행을 계산하므로 하루 전체 기상자료가 일괄 소실된 현상과도 구분된다. 여름을 포함한 연속 기간이 빠져 AI1 평가자료에 시간적 편중이 생긴다.

원본 대조 예시:

| 파일 | 관측소 | 원본 시각 | 누적강수량 |
| --- | --- | --- | ---: |
| 2024-03-29_2024-04-11_59051fcb85f2.csv | 011104F031 | 2024-04-09 23:50 | 0.0 |
| 같은 파일 | 같은 관측소 | 2024-04-09 24:00 | 행 없음 |
| 같은 파일 | 같은 관측소 | 2024-04-10 00:10 | 0.0 |

확정할 수 있는 사실은 **현재 보관된 원본 CSV에 해당 행이 없다는 것**이다. 센서가 관측하지 않았는지, 제공 시스템이나 다운로드·내보내기 과정에서 누락됐는지는 현재 로컬 파일만으로 구분할 수 없다. 모든 관측소가 같은 기간에 영향을 받으므로 원본 제공·수집 경로를 우선 확인한다.

후속 조치:

- 원본 제공처의 자정·24:00 표기 규칙과 내보내기 조건을 확인한다.
- 해당 기간을 일부 날짜·관측소부터 재조회하여 24:00 또는 00:00 행을 확보할 수 있는지 대조한다.
- 확보한 자료의 시각 의미와 중복을 확인한 뒤 정제자료 갱신 여부를 결정한다.
- 24:00 행이 없다는 이유로 23:50 값을 일강수량 최종값으로 대신 사용하지 않는다.

## P0 자정 누적값 0 처리와 일강수량 보조자료 부재

`gyeonggi_weather.ipynb`의 `regular_rain_grid`는 자정 누적값이 양수인 경우만 유지한다.

```python
end_values = rain.loc[end_times].where(rain.loc[end_times].gt(0))
```

일강수량 보조파일이 있으면 그 값을 우선 결합하지만, 현재 `worker/data/gyeonggi_daily_rainfall.csv`는 없다. 따라서 자정 누적값 0은 구간 증분 계산에 사용할 수 없다.

평가기간 선행 구간에서 이 규칙의 영향을 받은 자정 구간은 2,528개다. 그중 2,523개는 원본 23:50 누적값이 양수인데 24:00에 0으로 바뀐 경우다. 예를 들어 포천 영북면은 2023-12-31 23:50 누적값 11.0mm, 24:00 값 0.0mm이며 2024-01-01 작업일의 선행강수에 영향을 준다.

이는 **비가 안 와서 0인 경우와 누적계 초기화 0을 혼동하면 안 된다**는 근거다. 마지막 10분의 강수량을 모르므로 무조건 0으로 채우는 수정은 부적절하다. 이 규칙은 보수적인 설계이며, 이번 진단만으로 단순 구현 버그라고 판정하지 않는다.

후속 조치:

- 동일 관측소·동일 날짜의 공식 일강수량 또는 원래 10분 증분자료 확보를 우선 검토한다.
- 제공처의 초기화 시각과 24:00 값 의미를 확인한다.
- 보완 후에도 해석 불가능한 구간은 결측으로 유지한다.

2,468행은 선행강수에서 이 문제만 있으며, 그중 2,298행은 다른 AI1 입력도 완전하다. 이는 **자정값을 신뢰할 수 있게 복원할 경우의 조건부 활용 가능 수**이지, 지금 바로 복구 가능한 행 수가 아니다.

## P1 포천 신북면의 풍속 원본 결측

포천 신북면 `487915A001`은 평가 731일 모두 AI1 계산 불가다. 원본에서 확인한 작업시간 풍속 39,411개가 전부 `-`이고 유효 풍속은 0개다. 정제자료에서도 같은 결측이 유지됐다. 예정 39,474개 구간과의 나머지 차이는 관측 행 자체가 없는 구간이다.

따라서 이 관측소의 100% 제외를 선행강수 문제만으로 설명할 수 없다. 저장된 진단상 AI1 학습 사용 행도 0이므로, 현재 AI1 모델은 대상 24개 관측소 중 실제로는 **23개 관측소의 자료로 학습**했다. AI2는 24개 관측소 자료를 사용했다.

후속 조치:

- 해당 관측소가 풍속을 제공하는지 또는 별도 풍속 채널이 있는지 확인한다.
- 풍속을 확보하지 못하면 현행 두 모델 구조에서 AI1은 계산 불가로 유지하고 AI2만 제공한다.
- 다른 관측소의 풍속을 임의로 대입하거나 결측을 무풍 0으로 해석하지 않는다.

## 관측소별 편중

선행강수 문제는 특정 한 곳에 국한되지 않는다. 공통 자정 부재는 24곳 모두에 나타나며, 자정 누적값 초기화의 영향과 기타 누락 정도가 관측소별 차이를 만든다.

| 관측소 | AI1 제외 / 731일 | 제외율 | 선행강수 불완전 일수 |
| --- | ---: | ---: | ---: |
| 포천 신북면 487915A001 | 731 | 100.00% | 349 |
| 이천 중리동 467800A001 | 371 | 50.75% | 369 |
| 광주 목현동 464030A001 | 358 | 48.97% | 357 |
| 포천 영북면 011104F031 | 353 | 48.29% | 352 |
| 연천 연천읍 486803A001 | 353 | 48.29% | 351 |
| 가평 가평읍 477802A001 | 207 | 28.32% | 204 |
| 고양 덕양구 412040A002 | 187 | 25.58% | 185 |

전체 24개 관측소 내역은 `prior_rain_station_audit.csv`에 있다. 제외일은 원인별로 겹칠 수 있으므로 풍속 제외일과 선행강수 제외일을 단순 합산하지 않는다.

## P1 기타 원본 누락과 누적강수 비단조성

평가기간 선행강수의 결측 10분 구간을 원인별로 분류한 결과다. 한 작업일에 여러 구간이 있을 수 있으므로 아래 합계는 제외 작업일 수가 아니다.

| 원인 | 결측 10분 구간 수 |
| --- | ---: |
| 원본에도 관측 행 없음 | 14,163 |
| 자정 누적값 0 처리 | 2,528 |
| 이전 누적 기준값 결측 또는 이전 행 부재 | 1,276 |
| 현재 누적값 결측 | 298 |
| 누적강수량이 감소해 음의 차분 발생 | 176 |
| 원인을 설명하지 못한 파생 결측 | 0 |

현재 누적값 결측에는 원본의 `-`가 확인됐다. 음의 차분은 원본 누적값 자체가 감소한 경우다. 예를 들어 영북면 2024-07-06은 16:10의 10.5mm에서 16:20의 0.0mm로 바뀐다. 자정 밖의 초기화·장비 보정·자료 의미를 확인하기 전에는 차분을 0으로 바꾸지 않는다.

## P1 초안 검증 범위와 결과 해석

STEP04 선행 144개 구간의 유효 개수를 별도로 재계산한 결과, 저장된 STEP04와 불일치는 0건이다. 결측 시각의 현재 누적값이 존재하는 원본과 정제자료 간 대조도 불일치 0건이었다. 이번 범위에서 STEP04가 시각 경계를 잘못 잡거나 원본의 유효 누적값을 임의로 없앤 증거는 발견되지 않았다.

그러나 기존 STEP03 저장 집계와 STEP04 저장 집계의 일치만으로 원본의 완전성까지 보장하지는 않는다. 양쪽 모두 같은 정제자료를 사용하기 때문이다. 향후 실행 진단에는 다음을 구분해야 한다.

- 원본 행 부재
- 원본 값 결측
- 누적계 초기화 또는 음의 차분으로 파생값 산출 불가
- 작업일 특성 부족
- 모델 자체의 학습 또는 추론 실패

현재 평가자료의 여름철 공통 누락과 극단 관측일 제외 때문에, 산출된 점수는 **계산 가능한 관측소·날짜에 대한 이상도 결과**로 해석한다. 정상 실행·테스트 통과와 전체 평가기간 대표성은 별개의 문제다.

## 후속 작업 순서

1. 원본 제공·수집 경로에서 2024년 공통 자정 행 부재 원인을 확인한다.
2. 공식 일강수량 또는 10분 증분자료와 자정 초기화 규칙을 확보한다.
3. 신북면 풍속 채널 제공 여부를 확인한다.
4. 보완자료와 원인별 처리 규칙을 확정한 뒤 정제 갱신·STEP03 재산출 필요 범위를 검토한다. STEP03은 별도 요청 없이 변경하지 않는다.
5. 자료 갱신이 승인된 경우 STEP04를 다시 학습한다. 학습·전처리·백분위 기준은 여전히 2023년까지로 제한한다.
6. 관측소·연도·월·계절별 계산률과 극단 관측일의 포함률을 이전 결과와 비교한다. 평가점수를 유리하게 만들기 위한 기준 조정은 하지 않는다.

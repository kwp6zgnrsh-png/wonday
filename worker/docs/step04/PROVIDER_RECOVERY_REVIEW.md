# 자정 자료 재조회와 선행강수 복원 검토

2026-11-24 확인. 기존 STEP03, 생산용 STEP04 코드, 정제자료, 학습 모델과 점수는 변경하지 않았다. 아래 복원 수치는 제공처 일자료와 원본 누적값을 대조한 후보 결과이며 생산 산출값은 아니다.

공식 재조회 샘플에서도 자정 부재가 재현되므로 로컬 CSV 변환만의 문제로 볼 수 없다. 다만 제공처의 다른 API나 별도 원시 저장소에 값이 있는지는 이 샘플만으로 확정할 수 없다.

## 확보 경로

### 농업날씨365 웹

[농업기상관측자료 다운로드](https://weather.rda.go.kr/weather/obsrDataDwnld.do)에서 자료형태를 **10분 자료** 또는 **일 자료**로 선택하고 기존 관측소 코드·기간·강수량을 지정한다. 화면은 최대 10건 미리보기이며 전체 파일은 신청하기로 다운로드한다. 신청 단계에는 활용용도·활용분야·소속 입력이 필요하다. 이번에는 공개 조회만 사용했고 활용정보 신청은 제출하지 않았다.

[지점별 기간별조회](https://weather.rda.go.kr/analysis/inquiry.do)에서도 관측소와 년·월·일을 선택해 10분 또는 일별 표를 볼 수 있다. 이번 샘플은 공개 조회 기능의 응답 표를 저장해 확인했다. 내부 조회 주소는 웹 구현에 따라 바뀔 수 있어 장기 수집은 공개 API 또는 공식 다운로드를 우선한다.

웹 화면 담당 연락처는 **063-238-2144**다. 문의할 내용은 다음과 같다.

- 2024-04-09~2024-10-08의 24:00 행 부재와 00:00 표기 여부
- 24:00 강수량 0의 초기화 의미, 일강수량의 집계 시각 기준과 품질 표시
- 기존 관측소 코드별 과거 일강수량 일괄 제공 가능 여부
- 신북면 487915A001의 풍속 센서·별도 채널 제공 여부

### 공공데이터포털 API

[농진청 기본 관측데이터 API](https://www.data.go.kr/data/15078057/openapi.do)는 같은 관측소 코드로 10분 자료와 월·년·기간별 일자료를 조회하는 기능을 제공한다. 현재 공시된 기본 서비스 주소는 `https://apis.data.go.kr/1390802/AgriWeather/WeatherObsrInfo/V3/GnrlWeather`다. 서비스키가 필요하며 이번에는 키를 사용한 인증 API 호출은 하지 않았다.

[상세 관측데이터 API](https://www.data.go.kr/data/15078194/openapi.do)도 별도로 있다. 신북면의 대체 풍속 채널이 실제로 존재하는지는 상세 항목과 해당 관측소 응답을 확인해야 하며, 상세 API가 있다는 사실만으로 풍속 복구를 보장하지 않는다.

이전 기술명세의 기능명은 `getWeatherTenMinList`, `getWeatherMonDayList`, `getWeatherYearDayList`, `getWeatherTermDayList`다. [기관 작성 기술명세](https://agri.jeju.go.kr/seogwipo/communications/hardship.htm?act=download&no=1&page=8&seq=53792)는 구버전이므로 현재 포털의 버전·파라미터를 우선한다. 특히 구버전 `obsr_Spot_Code`와 현행 공시 `obsr_Spot_Cd`, 페이지 크기 제한을 혼용하지 않는다.

기상청 ASOS·AWS 일자료는 관측망·지점코드가 다르다. 농진청 같은 지점의 공식 일자료를 먼저 확보하고, 근처 기상청 지점 자료를 동일 관측소의 정답처럼 덮어쓰지 않는다.

## 자정 행 없이 선행 24시간을 구하는 방법

작업일 d의 08:00 직전 24시간은 다음 식으로 계산할 수 있다.

```text
선행 24시간 강수량
= 전날 공식 일강수량
  − 전날 08:00까지의 누적강수량
  + 당일 08:00까지의 누적강수량
```

공식 일자료와 누적계가 같은 관측소·KST 일자 기준을 사용하고, 08:00 누적값이 유효하며 중간 비정상 초기화가 없어야 한다. 일강수량이 있다고 모든 누락을 해결한 것으로 처리하지 않는다. 시간 기준·품질 상태를 확인하고 음의 결과, 일총량보다 큰 누적값 등을 검사한다.

| 영북면 작업일 | 전날 일강수량 | 전날 08:00 누적 | 당일 08:00 누적 | 복원 후보 |
| --- | ---: | ---: | ---: | ---: |
| 2024-01-01 | 11.0 | 4.0 | 0.0 | 7.0mm |
| 2024-04-10 | 0.0 | 0.0 | 0.0 | 0.0mm |
| 2024-04-16 | 14.0 | 0.0 | 0.0 | 14.0mm |

또는 전날 일총량에서 23:50 누적량을 빼 마지막 10분 증분을 구할 수 있다. 현재 전처리는 일자료 결합 후에도 원래 없는 자정 행을 최종 정제 CSV에 생성하지 않으므로 **일자료 파일을 추가하는 것만으로는 현재 파이프라인의 모든 자정 결측이 해결되지 않는다.** 반영 방식은 별도 설계·검증이 필요하다.

공식 일강수량 자체를 선행 24시간 강수량으로 바로 대체해서도 안 된다. 하루 00:00~24:00과 작업 직전 08:00~08:00은 다른 구간이다.

## 모든 날에서 자정 구간을 제외하는 대안

가능한 모델링 선택이다. 00:00은 순간값 하나가 아니라 **전날 23:50~24:00의 10분 구간 종료시각**이므로, 이를 빼면 특성은 다음과 같이 바뀐다.

- 원래 특성: 선행 24시간의 144개 구간 합
- 대안 특성: 선행 24시간 범위에서 자정 10분 구간을 제외한 **고정 143개 구간 합**

대안은 연속된 23시간50분 이동창이 아니라 중간 10분이 빠진 합이다. 모든 관측소·날짜와 학습·평가·추가기간에 같은 규칙을 적용하고 새 특성명·버전을 써야 한다. 자정값이 있는 날만 144개를 사용하거나 143개 합을 24시간 합이라고 부르지 않는다. 144/143 비례 확대도 강수가 균등하다는 근거가 없어 적용하지 않는다.

현재 평가자료에서 입력 가능성만 계산한 결과다. 새 모델을 학습하거나 점수를 생성한 결과는 아니다.

| 대상 | 현행 사용 가능 | 고정 143개 대안 사용 가능 | 대안 제외율 |
| --- | ---: | ---: | ---: |
| 24개 관측소 17,544행 | 9,826 | 16,206 | 7.63% |
| 신북면 제외 16,813행 | 9,826 | 16,206 | 3.61% |

이 수치는 자료 활용률 진단이며 모델 성능 개선을 입증하지 않는다. 채택하면 2023년까지의 자료로 모델과 백분위 기준을 새로 만들어야 한다. 평가 점수가 유리한 규칙을 고르는 방식으로 사용하지 않는다. STEP03의 원래 24시간 정의는 별도 변경 없이 유지한다.

우선순위는 같은 관측소의 공식 일자료로 실제 24시간 합계를 복원할 수 있는지 확인하는 것이다. 고정 143개 특성은 실제 24시간 합계가 필요하지 않다는 모델 설계 판단에 따라 선택할 수 있는 대안이다.

## 신북면 제외의 의미

AI1은 이미 완전 입력 행만 학습하므로 신북면의 학습 사용 행은 0이다. **AI1에서 신북면을 명시적으로 제외해도 현행 학습 표본은 바뀌지 않는다.** 평가 분모를 23개 관측소로 좁히면 현행 제외율은 43.99%에서 41.56%가 되지만 나머지 관측소의 결측은 해결되지 않는다.

AI2에는 신북면의 유효 온열자료가 포함돼 있다. 풍속 결측 때문에 AI2까지 삭제할 필요는 없다. 운영·보고에서는 AI1 관측소 지원 범위를 명시하고, 제외한 관측소가 분모에서 사라져 성능이 개선된 것처럼 보이지 않게 전체 24곳과 지원 23곳의 계산률을 구분한다.

# STEP04 기상 AI 이상지수 제안 및 요구사항 정의서

작성일: 2026-11-25

상태: 초기 모델 구현 완료. 공식 일강수량 원자료를 먼저 공유하고, 데이터 검토 후 복원 로직 반영·재학습·추가 검증을 진행한다. 이 문서의 후속 기능이 모두 현재 코드에 구현됐다는 뜻은 아니다.

## 1 목적과 범위

실제 농작업 취소 라벨이 없는 상황에서 기상자료의 과거 대비 이례성을 학습한다. Isolation Forest 주 모델 두 개로 강수·강풍 AI1과 온열 AI2를 산출한다. 이상점수는 취소·피해 확률이 아니다.

| 구분 | STEP04 | STEP05 |
| --- | --- | --- |
| 수행 내용 | 공식 일자료 확보·품질 검증, 특성 집계·복원, 두 IF 학습, 이상점수 변환, 제외율·유용성 비교 | 작목·농작업 정보 연결, 기존 지수와 AI 지수 결합, R1·R2 척도·가중치 및 지급 기준 검토 |
| 보조 모델 | 사용하지 않음 | 필요 시 별도 논의 |

이번 선행 납품은 공식 일강수량 원자료와 설명자료다. 팀원이 다른 모델을 실험할 수 있도록 모델에 종속되지 않는 CSV와 출처 응답을 제공한다. 데이터 전달 전에 기존 특성을 복원하거나 실제 모델을 재학습하지 않는다.

## 3 데이터 계약

### 3.1 계산 단위와 기간

- 대상: 기존 24개 관측소, 관측소·작업일별 계산.
- 기본 작업시간: KST 08:00~17:00. 08:10~17:00 종료 구간 54개를 사용한다.
- 선행강수: 전날 08:10~당일 08:00 종료 구간 144개, 실제 범위는 작업 시작 직전 24시간이다.
- 학습 작업일: 2016-01-01~2023-12-31. 기존 대상 65,638행.
- 평가 작업일: 2024-01-01~2025-12-31. 기존 대상 17,544행.
- 2026년은 별도 추가기간이며 이번 학습·평가 원자료 공유 범위와 구분한다.
- 늦게 시작한 4개 관측소는 확보한 학습기간을 기록하고 포함한다.

공식 일자료의 날짜와 모델 대상 작업일은 다르다. 예를 들어 2024-01-01 작업일의 선행강수에는 2023-12-31 공식 일자료가 필요하다. 학습·평가 구분은 **대상 작업일**을 기준으로 하며 공식 자료의 연도만 보고 행을 분류하지 않는다. 최초 작업일의 전날 등 경계일 자료를 별도로 표시한다.

| 자료 | 출처 및 용도 | 키 |

## 6 선행 24시간 강수 복원 규칙

### 6.1 계산식

작업일 d의 작업 시작이 08:00인 경우:

```text
P24(d) = 공식 일강수량(d-1)
         - 누적강수량(d-1, 08:00)
         + 누적강수량(d, 08:00)
```

다른 작업 시작시간을 지원할 때는 같은 시작시각 기준으로 일반화하고 별도 검증한다. 00:00을 단순 삭제하거나 143개 구간 합을 24시간 강수량이라고 부르지 않는다. 공식 일강수량만으로 P24를 대체하지 않는다.

### 6.2 사용 조건과 보류

보수적 첫 반영은 기존 P24가 결측인 행 중 다음을 모두 만족한 경우로 한정한다.

1. 같은 관측소의 공식 전날 일강수량이 유효하고 조회 간 충돌이 없다.
2. 전날·당일 작업 시작시각 누적값이 유효하다.
3. 공식 일자료와 누적계의 KST 일자·구간 정의가 일치한다.
4. 관련 구간에서 누적계의 비정상 감소나 일총량과의 모순이 없다.
5. 자정 외 143개 강수 증분이 유효하다.
6. 공식 일총량 − 전날 23:50 누적값으로 구한 마지막 10분 증분이 음수가 아니다.
7. 143개 구간 합 + 복원 마지막 구간 합이 P24 계산식과 허용 오차 내에서 일치한다.

허용 오차는 원자료 정밀도를 근거로 명시한다. 기존 진단의 0.001mm 대조를 초기 기준으로 하되, 허용 오차로 실제 음수·충돌·센서 이상을 숨기지 않는다.

자정 외에도 누락이 있는 합계 복원 후보는 첫 생산 반영에서 자동 수용하지 않고 별도 검토군으로 둔다. 기준 누적값 결측·비정상 감소·일자료 부재·출처 충돌은 보류한다. 완전 관측이었던 기존 값과 공식 자료가 다르면 기존 값을 조용히 덮어쓰지 않는다.

### 6.3 출처 기록

각 작업일에 최소한 다음을 기록한다.

- prior_rain_source: observed_10min / reconstructed_official_daily / unavailable
- 원래 관측 구간 수와 결측 수: 복원해도 144개를 관측했다고 표시하지 않음
- 공식 전날 일자료 날짜·값·조회 식별자
- 전날·당일 작업 시작 누적값
- 원래 P24·복원 후보 P24·최종 사용값
- 복원 적격 여부와 보류 사유
- 특성 정의·복원 정책 버전

별도 STEP04 특성에서 P24를 복원한다. 다른 작업시간 특성·강수 지속시간까지 일총량으로 복원하지 않는다. STEP03 지수·분위수·기존 결과는 변경하지 않는다.

## 7 모델 적격성 및 신북면 정책

| 모델 | 사용 조건 |
| --- | --- |
| AI1 | 강수·풍속 5개 특성이 모두 유효하고 AI1 지원 대상 관측소임 |
| AI2 | 온열 3개 특성이 모두 유효함 |

P24는 완전한 관측 또는 위 규칙을 충족한 복원으로 유효할 수 있다. 다른 특성은 기존 예정 구간 완전성 기준을 유지한다. 입력 부족을 0으로 대치하거나 같은 모델의 입력 열을 행마다 바꾸지 않는다.

**포천 신북면 487915A001은 AI1 학습·추론에서만 명시적으로 제외한다.** 풍속 결측을 무풍으로 처리하지 않는다. AI2의 유효 기온·습도는 유지한다. 원자료와 전체 결과 행은 삭제하지 않으며 AI1에서 station_excluded_wind_unavailable 사유를 기록한다.

자료의 입력 부족, 정책상 관측소 제외, 모델 학습 불가를 구분해 기록한다. 전체 24곳과 AI1 지원 23곳의 제외율 분모를 따로 제공한다. component_scores_complete로 공통 필터링하지 않는다.

## 8 학습과 이상점수 변환

| ID | 요구사항 |
| --- | --- |
| MODEL-01 | 학습은 2016~2023년 대상 작업일의 모델별 적격 행만 사용 |
| MODEL-02 | 2024~2025년은 평가에만 사용. 2026년은 별도 산출 |
| MODEL-03 | 기본 수치 전처리는 원단위·결측 대치 없음·극단값 자동 절삭 없음 |
| MODEL-04 | 기본 IF는 300개 트리·max_samples=auto·max_features=1.0·contamination=auto·bootstrap=False·seed=42 |
| MODEL-05 | 설정 비교는 학습기간 내부의 시간순 검증으로 수행. 평가 점수에 맞춰 선택하지 않음 |
| MODEL-06 | 낮을수록 이상한 score_samples의 부호를 뒤집고 해당 학습분포의 ECDF로 0~100점 변환 |
| MODEL-07 | 모델·입력 열 순서·작업시간·복원 정책·라이브러리 버전·학습 범위·모델 식별자를 함께 저장 |
| MODEL-08 | 저장 모델의 입력 계약이 다르면 재추론을 중단. 실제 학습 참여 여부와 추론 적격성 분리 |

각 모델의 실제 학습 행 전체를 점수화하여 기준분포를 만든다. 동점은 동일한 오른쪽 누적순위를 적용한다. 설정·특성·학습자료가 바뀌면 기존 모델과 ECDF를 재사용하지 않는다. 모델 부족 시 다른 모델을 평가자료로 대신 학습하지 않는다.

| P24 | 기존 결측, 보수적 후보, 추가 검토, 보류 사유, 기존 완전값과 불일치 |
| 동일 행 | 복원 전후 모두 계산된 동일 키에서 점수 차이·순위 변화 비교 |
| 추가 행 | 복원으로 새로 계산된 행을 기존 행과 분리해 설명 |
| 기상 사건 | 강수·강풍·온열 극단 관측일의 포함·제외 및 점수 현황 |
| 관측소 지원 | 전체 24곳과 AI1 지원 23곳을 구분 |

대상 행이 늘어난 결과와 동일 행의 모델 점수가 바뀐 결과를 혼동하지 않는다. 복원 전 산출물과 새 산출물은 별도 폴더·별도 모델 식별자로 보존한다.

## 10 검증과 수용 기준

### 구현 검증

- 학습·평가 날짜 경계와 이전 일자료 연결, 윤일·연말·늦은 관측 시작일을 확인한다.
- 정상 0·결측·음수·출처 충돌·누적계 초기화를 구분한다.
- 기존 관측 기반 P24와 독립 복원 계산을 대조하고 불일치가 미해결이면 해당 행을 보류한다.
- 복원 출처와 원래 관측 수를 보존하고 제외 사유·분모 합계를 검증한다.
- 신북면 AI1 제외·AI2 유지와 두 모델의 독립 적격성을 검증한다.
- 평가·추가기간 극단값을 바꿔도 학습 모델·전처리 기준·ECDF가 변하지 않는지 확인한다.
- 모델 재로딩 후 점수 일치, 입력 계약 불일치 거부, 전체 대상 행 보존을 확인한다.
- STEP03·기존 모델·원본자료가 요청 없이 변경되지 않았는지 확인한다.

### 유용성 검증

단위 테스트 통과와 탐지 성능은 별개다. 단순 기상 기준과의 비교, 학습기간 내부 시간순 검증, 난수 시드별 순위 안정성, 사건·계절·관측소별 결과를 확인한다. 팀원이 다른 모델을 비교할 때는 같은 데이터 버전·대상 키·분할·결측 정책을 사용하고 전처리도 학습자료에서만 맞춘다.

실제 취소 라벨이 없으므로 취소 정확도·확률을 주장하지 않는다. 같은 기상자료에서 만든 극단 표시와의 일치는 일관성 진단이며 독립 정답 검증이 아니다. 현재 AI1 강풍 지속시간의 양수 학습 행 1개, AI2의 -40℃ 의심값 등은 품질·표본 검토 대상이다.

## 12 진행 순서

1. 공식 일강수량 원자료를 확보하고 팀원 공유 패키지와 이 요구사항을 전달한다.
2. 학습기간 자료의 품질·누락·출처 충돌 및 현재 모델 입력과의 연결을 검토한다.
3. 합의한 보수적 복원 로직과 테스트를 STEP04에 구현한다.

5. 복원 전후 계산률·사건 포함·점수·모델 안정성을 비교한다.
6. 한계와 추가 가치를 정리한 뒤 STEP05 결합 정책을 논의한다.

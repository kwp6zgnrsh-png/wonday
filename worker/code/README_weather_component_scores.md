# 개별 기상위험지수 산출

`weather_component_scores.py`는 지정 관측소의 10분 자료로 작업일별 강수·강풍·온열 위험을 산출합니다. Python 3.10 이상에서 외부 패키지 없이 실행합니다.

## 실행

저장소 루트 `C:\Users\user\wonday`에서 실행합니다.

```powershell
python worker/code/weather_component_scores.py
```

기본 설정은 가평읍 `477802A001`, 비산지, 매일 **08:00~17:00**, 학습 **2016-01-01~2023-12-31(8년)**입니다. 2024년 이후는 검증기간으로 표시합니다. 실제 작업 일정이 없으므로 입력기간의 모든 날짜를 예정 작업일로 가정합니다. 기본값은 작업현장에 맞게 바꿀 수 있습니다.

```powershell
python worker/code/weather_component_scores.py --station-code 477802A001 --work-start 08:00 --work-end 16:00
python worker/code/weather_component_scores.py --station-code 477802A001 --mountain
```

작업시간은 10분 경계에 맞춰 같은 날짜 안에서 지정합니다. 종료 `24:00`도 허용합니다. 관측소 위치만으로 산지 여부를 추정하지 않으므로, 산지 기준을 적용할 때 `--mountain`을 명시합니다.

기본 파일:

| 용도 | 경로 |
| --- | --- |
| 입력 | `worker/data/gyeonggi_processed/weather_clean.csv` |
| 출력 | `worker/data/gyeonggi_processed/weather_component_scores.csv` |
| 강수 분위수 | `worker/data/gyeonggi_processed/rain_calibration_477802A001.json` |

다른 경로는 `--input`, `--output`, `--calibration`으로 지정합니다. 여러 관측소나 작업시간을 계산할 때는 출력·분위수 파일 경로를 각각 구분하세요. 같은 경로의 결과 CSV는 다시 실행하면 교체됩니다. 서로 다른 입력·출력·분위수 경로를 강제하고, 각 파일은 임시 파일 작성 후 교체합니다.

## 입력 계약

기존 노트북의 STEP01에서 생성하는 정제 파일을 그대로 읽습니다. STEP02의 일별 집계 파일은 필요한 이동강수량과 시각별 기온·습도를 복원할 수 없어 입력으로 사용하지 않습니다.

| 열 | 의미 |
| --- | --- |
| `station_code` | 문자열 관측소 코드(앞의 0 보존) |
| `observed_at` | 한국시간, 시간대 표기 없는 **구간 종료시각**, 10분 간격 |
| `temperature_c` | 기온, ℃ |
| `humidity_pct` | 같은 구간의 상대습도, 0~100% |
| `wind_mps` | 10분 평균풍속, m/s |
| `rain_10min_mm` | 해당 10분 구간의 강수 증가량, mm |
| `gust_mps` | 선택 열. 해당 10분 구간에서 관측된 최대 순간풍속, m/s |

예를 들어 08:00~17:00 작업에는 **08:10~17:00 종료 구간 54개**를 사용합니다. 08:00 종료 구간은 선행강수에 속합니다. 직전 24시간은 전날 08:10부터 당일 08:00까지 144개 구간입니다. 원본의 일 누적강수량을 증가량으로 변환하는 작업과 `24:00` 누적계 초기화 처리는 기존 STEP01에서 수행합니다. 정제 파일의 `rain_3h_mm`는 작업시간 밖을 포함할 수 있어 사용하지 않고, 작업시간 내부에서 다시 계산합니다.

현재 정제 파일에는 순간풍속 열이 없으므로 평균풍속으로 강풍을 평가하고 `gust_evaluation_status=unavailable`로 기록합니다. 순간풍속 자료를 확보하면 `gust_mps` 열을 추가하면 됩니다.

## 산출 규칙

각 지수를 내부에서 0~1로 계산한 뒤 **CSV의 `S_R`, `S_W`, `S_H`는 0~100점**으로 저장합니다. 세부 점수는 0~1을 유지합니다. 중간 계산은 반올림하지 않고 출력할 때 소수점 6자리로 반올림합니다.

1. **강수**: 완전한 연속 6개 구간의 강수합이 72mm 이상, 또는 연속 18개 구간의 합이 90mm 이상이면 100점입니다. 창 전체가 예정 작업시간에 들어와야 합니다. 그 외에는 작업 중 강수 점수 70%와 선행 24시간 강수 점수 30%를 합칩니다.
2. **강풍**: 비산지 평균풍속 21m/s 또는 순간풍속 26m/s, 산지 평균풍속 24m/s 또는 순간풍속 30m/s 이상이면 100점입니다. 그 외에는 최고 강도 75%와 지속시간 비율 25%를 합칩니다. 평균풍속 강도는 비산지 `0·14·21`, 산지 `0·17·24`, 순간풍속 강도는 비산지 `0·20·26`, 산지 `0·25·30`을 `0·0.70·1`로 선형 환산하며 둘 중 높은 점수를 씁니다. 지속시간은 평균풍속 14m/s(산지 17m/s) 이상인 시간 / 예정 작업시간입니다.
3. **온열**: 같은 구간의 기온·습도로 기상청 여름철 체감온도를 계산합니다. 38℃ 이상인 유효 관측이 하나라도 있으면 100점입니다. 그 외에는 최고 강도 60%와 노출시간 40%를 합칩니다. 최고 강도는 31℃ 미만 0, `31·33·35·38℃`에서 `0.25·0.50·0.75·1`로 선형 환산합니다. 31℃에서 0.25로 오르는 불연속은 제시한 설계를 따릅니다. 노출시간 점수는 `min(31℃ 이상 시간 / (예정 작업시간 × 0.75), 1)`입니다.

체감온도는 Stull 습구온도 추정식과 기상청 공식의 **+3.0 보정항**을 포함합니다. 온열 위험 평가에는 겨울철 체감온도식으로 전환하지 않고 이 여름철 공식을 적용합니다. [기상청 공식 및 설명(2023년 보도자료)](https://www.weather.go.kr/kma/news/press.jsp?mode=view&num=1194231)

제시된 예시인 8시간 작업, 최고 체감온도 34℃, 31℃ 이상 6시간이면 `S_H=77.5`입니다.

## 강수 분위수의 학습·재사용

최초 실행 시 학습기간의 완전한 작업 중 강수합과 선행 24시간 강수합에서 **양수만** 모아 각각 P50·P90·P99를 구합니다. 분위수는 `(n-1)×p` 위치를 선형 보간합니다. `0mm→0, P50→0.25, P90→0.75, P99→1`이며 P99 이상은 1입니다.

관측의 이산성으로 분위수가 같아지면 같은 강수량에 서로 다른 점수를 부여할 수 없습니다. 이 경우 **같은 기준점 중 높은 점수**를 사용하고, 0mm는 항상 0으로 둡니다. 각 강수 변수에 양수 학습 표본이 없으면 임의의 기준을 만들지 않고 오류를 냅니다.

분위수 JSON에는 관측소·작업시간·학습기간과 양수 표본 수를 기록합니다. 이후 실행에서는 기존 JSON을 그대로 읽으며, 검증자료로 분위수를 다시 계산하지 않습니다. 메타데이터가 실행 설정과 다르면 오류를 냅니다. 검증기간 자료만 있는 입력도 기존 JSON을 지정하면 계산할 수 있습니다.

학습기간은 종료일을 포함해 정확히 8년이어야 하며, 최초 학습용 입력은 이 기간을 포함해야 합니다. 기간 내 결측 합계는 해당 변수의 학습 표본에서 제외합니다. 의도적으로 기준을 다시 학습할 때만 실행합니다.

```powershell
python worker/code/weather_component_scores.py --refit-calibration
```

## 결측과 결과 해석

`X`, 빈 값, `-`, 비유한 수는 결측으로 처리합니다. 음수 강수·풍속과 0~100% 밖의 습도도 결측입니다. 유효 기온과 습도가 같은 시각에 모두 있어야 온열 구간이 유효합니다. 같은 관측소·시각의 동일 중복 행은 한 번만 사용하고, 값이 충돌하면 오류를 냅니다.

**관측된 값으로 만점 기준을 충족하면 다른 구간이나 세부 점수가 결측이어도 100점**입니다. 만점 미만 가중합은 강수의 작업 중·선행 구간, 강풍의 평균풍속 구간, 온열의 기온·습도 쌍이 각각 전부 유효할 때 계산합니다. 부족하면 해당 최종 점수를 빈칸으로 남기고 `missing_data`로 표시합니다. 결측을 0점으로 간주하거나 유효 관측시간으로 분모를 줄이지 않습니다.

순간풍속은 선택 자료입니다. 일부만 있으면 관측된 최고 순간풍속을 강도·만점 판정에 반영하며 `partial`을 기록합니다. 평균풍속이 완전하면 가중합도 계산할 수 있지만, 미관측 구간의 더 큰 돌풍을 배제할 수는 없습니다. 다른 부분 관측 최댓값·노출시간도 함께 저장하므로 해당 구간 수와 점수 상태를 함께 확인하세요.

주요 결과 열:

| 열 | 의미 |
| --- | --- |
| `S_R`, `S_W`, `S_H` | 강수·강풍·온열 최종 0~100점, 계산 불가 시 빈칸 |
| `*_full_score` | 해당 만점 기준을 실측값으로 충족했는지 |
| `*_score_status` | `override`: 만점 우선 적용, `ok`: 가중합, `missing_data`: 계산 불가 |
| `*_subscore` | 가중합에 사용한 0~1 세부 점수 |
| `gust_evaluation_status` | `unavailable`, `partial`, `complete` |
| `work_*_interval_count`, `prior_rain_interval_count` | 유효 구간 수 |
| `valid_1h_window_count`, `valid_3h_window_count` | 작업시간 내부의 완전한 이동 창 수 |
| `work_max_1h_rain_mm`, `work_max_3h_rain_mm` | 완전한 이동 창에서 확인된 최대 강수량 |
| `work_max_apparent_temp_c`, `work_heat_minutes_ge31` | 체감온도 최고값·31℃ 이상 관측 누적분 |
| `period` | `train`, `validation`, `before_train` |
| `rain_train_start`, `rain_train_end` | 적용한 분위수의 학습기간 |

실제 특보 발효 여부는 입력이나 만점 판정에 사용하지 않습니다. 이 코드는 사용자가 제시한 프로젝트 점수 설계를 구현합니다.
